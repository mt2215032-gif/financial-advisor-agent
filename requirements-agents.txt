 Optional extras for the framework agents in agents/.
 Install alongside requirements.txt:  pip install -r requirements-agents.txt

 Not needed for the Streamlit app, the native SDK loop, or the LangGraph
 agent - those run on requirements.txt alone.

 --- CrewAI -------------------------------------------------------------------
 Install plain crewai, NOT crewai[anthropic]: that extra pins anthropic~=0.73,
 which breaks the native SDK loop (needs anthropic>=1.0). CrewAI's bundled
Anthropic provider works fine against anthropic 1.x - verified on 1.2.0.
crewai>=1.15,<2.0
